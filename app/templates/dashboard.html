About
What This Application Does

This is an accounting data engineering pipeline for the Finz challenge. It turns messy bank exports into reviewed, classified, duplicate-safe accounting transactions, then ties the app output back to QuickBooks Sandbox.

Features
Pipeline Capabilities
  • CSV/XLSX upload with worksheet selection and column mapping
  • Normalization, duplicate detection, classification, and manual review
  • Cash-basis P&L with account-level drill-down
  • QuickBooks chart setup, sync, run history, and reconciliation
Review Logic
P&L and Confidence Scores

The P&L is computed only from approved canonical transactions. Confidence scores explain classification certainty: high-confidence rows can be approved quickly, while lower-confidence rows stay visible for human review before QBO sync.
